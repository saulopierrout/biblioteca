# Skills & Tools: biblioteca e protocolos

Biblioteca de skills, plugins, ferramentas, MCPs, guias, prompts, sites, cursos e certificações para trabalhar com IA, mais um conjunto de **protocolos** por tipo de projeto (aplicativo, motion, marketing, automação, dados, segurança, produtividade, estudo e outros).

- `index.html`: início, com painéis por objetivo, ranking e atalhos.
- `objetivos.html`: um painel para cada objetivo (protocolo, kit principal, sites, cursos e códigos).
- `skills.html`: a biblioteca completa (abas Skills & Tools, Sites, Cursos e Códigos, com ranking, miniaturas e preview ao vivo dos códigos).
- `protocolos.html`: os protocolos, com o kit principal de cada tipo de projeto e o botão de copiar o prompt.
- `animacao.html`, `animacao-filmes.html` e `animacao-efeitos.html`: referências de animação (estilos e combinação, filmes e vídeos com prompt, efeitos de vídeo). A cena fica em `animacao/cena/` (licença do motor em `animacao/LICENSE.txt`).

Página estática, sem dependências: é só abrir o link. Dados de estrelas, licenças e datas vêm da API do GitHub e mudam todo dia; leia o código antes de instalar qualquer item de terceiros e use, de preferência, um computador pessoal.
